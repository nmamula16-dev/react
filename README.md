# React + Vite პროექტი 🚀

თანამედროვე და სწრაფი React აპლიკაცია Vite-ის ბაზაზე.

## პროექტის გაშვება (Getting Started)

პროექტის საქაღალდეში შესვლა:
```bash
cd react-app
```

დამოკიდებულებების (dependencies) ინსტალაცია:
```bash
npm install
```
*(თუ PowerShell-ში სკრიპტების შეზღუდვის შეცდომა გამოჩნდება, გამოიყენეთ: `npm.cmd install`)*

დეველოპმენტ სერვერის გაშვება:
```bash
npm run dev
```
*(ან: `npm.cmd run dev`)*

ამის შემდეგ ბრაუზერში გაიხსნება მისამართი: `http://localhost:5173`

---

## პროექტის სტრუქტურა

```
react-app/
├── index.html           # მთავარი HTML ფაილი
├── package.json         # პაკეტების და სკრიპტების კონფიგურაცია
├── vite.config.js       # Vite კონფიგურაცია
├── public/              # სტატიკური რესურსები
└── src/
    ├── App.jsx          # მთავარი React კომპონენტი
    ├── App.css          # App კომპონენტის სტილები
    ├── index.css        # გლობალური სტილები
    └── main.jsx         # React აპლიკაციის საწყისი წერტილი
```
